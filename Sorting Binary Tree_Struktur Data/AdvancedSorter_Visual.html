Array Merge Sort

Menggunakan satu tmpArray tunggal berukuran n yang dialokasi sekali di awal. Setiap rekursi menggunakan virtual sublist tanpa membuat array baru.

def _merge_virtual(self, arr, left_start, mid, right_end, tmp_array):
    a, b, k = left_start, mid+1, left_start
    while a <= mid and b <= right_end:
        if arr[a] <= arr[b]:   # <= menjamin STABLE
            tmp_array[k] = arr[a]; a += 1
        else:
            tmp_array[k] = arr[b]; b += 1
        k += 1
    # salin sisa, lalu copy balik ke arr

Linked List Merge Sort

Menggunakan fast-slow pointer untuk split dan dummy node untuk merge. Tidak ada alokasi node baru selama sorting.

def _split_linked_list(self, head):
    mid_point = head
    cur_node  = head.next
    while cur_node and cur_node.next:
        mid_point = mid_point.next      # +1 langkah
        cur_node  = cur_node.next.next  # +2 langkah
    right_head     = mid_point.next
    mid_point.next = None             # putus di tengah
    return right_head

Quick Sort (Median-of-Three)

Pivot dipilih dari median tiga elemen (first, mid, last) untuk menghindari worst-case O(n²) pada data terurut. Jika kedalaman rekursi melebihi 2·log₂(n), otomatis fallback ke Merge Sort.

# Pilih median dari arr[first], arr[mid], arr[last]
if arr[first] > arr[mid]:   arr[first], arr[mid]  = arr[mid],  arr[first]
if arr[first] > arr[last]:  arr[first], arr[last] = arr[last], arr[first]
if arr[mid]   > arr[last]:  arr[mid],   arr[last] = arr[last], arr[mid]
arr[first], arr[mid] = arr[mid], arr[first]  # pivot ke depan

Mengapa tmpArray Tunggal Lebih Efisien?

Versi berbasis slice membuat array baru setiap rekursi → O(n log n) alokasi memori total.
Versi tmpArray tunggal hanya mengalokasi sekali O(n) di awal, lalu menggunakan indeks virtual untuk menunjuk segmen yang berbeda.

Fast-Slow Pointer — Cara Kerja

midPoint bergerak 1 langkah, curNode bergerak 2 langkah. Saat curNode mencapai akhir list, midPoint tepat berada di tengah — tanpa perlu menghitung panjang list terlebih dahulu.

Dummy Node di Linked List Merge

Dummy node menghilangkan pengecekan khusus untuk node pertama hasil merge. tail.next selalu bisa di-assign tanpa kondisi if/else tambahan. Tidak ada alokasi node baru — hanya pointer .next yang dimodifikasi.
