Expression Tree Builder

Pohon ekspresi dibangun secara rekursif dari ekspresi berparentesis penuh menggunakan antrian token (deque). Setiap ( memicu pembuatan node operator dengan dua anak.

def _build_tree(self, tokens):
    token = tokens.popleft()
    if token == '(':
        left     = self._build_tree(tokens)  # subtree kiri
        operator = tokens.popleft()          # ambil operator
        right    = self._build_tree(tokens)  # subtree kanan
        tokens.popleft()                     # konsumsi ')'
        return {'val': operator, 'left': left, 'right': right}
    else:
        return {'val': float(token), 'left': None, 'right': None}

Coba Bangun Pohon Ekspresi

Traversal Postorder (Notasi Postfix)

Mengapa postorder menghasilkan postfix otomatis?
Postorder mengunjungi kiri, kanan, lalu akar. Operator dicetak setelah kedua operandnya — persis definisi notasi postfix. Inorder memerlukan tanda kurung eksplisit karena operator dicetak di antara operand dan urutan prioritas bisa ambigu.

Konstruksi Max-Heap In-Place

Max-heap dibangun dari array biasa menggunakan metode bottom-up sift-down, mulai dari node internal terakhir (indeks n//2 - 1) ke atas.

# Fase 1: Build max-heap
for i in range(n // 2 - 1, -1, -1):
    self._sift_down(arr, n, i)

# sift_down: left=2i+1, right=2i+2
while largest != idx:
    arr[idx], arr[largest] = arr[largest], arr[idx]
    idx = largest

Heapsort In-Place

Setelah max-heap terbentuk, elemen terbesar (root) ditukar ke akhir array, lalu heap diperkecil satu elemen dan sift-down dijalankan dari root.

# Fase 2: Ekstraksi berulang
for end in range(n - 1, 0, -1):
    arr[0], arr[end] = arr[end], arr[0]  # swap root ke akhir
    self._sift_down(arr, end, 0)           # pulihkan heap

Complete Binary Tree Validator

Memvalidasi apakah suatu array dapat dipetakan ke complete binary tree tanpa "lubang". Semua node harus terisi level-by-level dari kiri ke kanan.

def is_complete_tree(self, arr):
    n = len(arr)
    found_none = False
    for i in range(n):
        left, right = 2*i+1, 2*i+2
        if left < n:
            if found_none: return False  # ada lubang!
        else:
            found_none = True
        if right < n:
            if found_none: return False
        else:
            found_none = True
    return True

Mengapa Heapsort Tetap O(n log n)?

Setiap operasi sift-down membutuhkan O(log n) langkah (tinggi pohon). Fase build-heap memanggil sift-down sebanyak n/2 kali, dan fase ekstraksi memanggil sift-down sebanyak n-1 kali. Total: O(n log n), meski swap dilakukan berulang pada array yang sama.

Postorder vs Inorder Traversal

Postorder menghasilkan notasi postfix secara otomatis karena operator selalu dicetak setelah kedua operandnya — sesuai urutan kunjungan kiri-kanan-akar.

Inorder memerlukan tanda kurung eksplisit karena operator dicetak di tengah operand. Tanpa kurung, ekspresi seperti 3 + 4 * 2 menjadi ambigu.

Batas Bawah Comparison Sort — Ω(n log n)

Heapsort tidak melanggar batas ini karena heapsort adalah comparison-based sort. Setiap perbandingan elemen tetap menentukan alur eksekusi. Batas Ω(n log n) berlaku untuk semua algoritma yang hanya menggunakan perbandingan, termasuk heapsort.
